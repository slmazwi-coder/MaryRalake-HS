# Mary Ralake High School Website

A modern school website for **Mary Ralake High School**, located in Maluti, Matatiele, Eastern Cape.

## School Information

- **Name:** Mary Ralake High School
- **Motto:** Success Through Perseverance
- **Type:** Public Secondary School (No-Fee)
- **Grades:** 8 – 12
- **Location:** Maluti, Matatiele, Eastern Cape, 4730
- **District:** Alfred Nzo West Education District
- **Former Name:** Maluti Junior Secondary School (Maluti JSS)

## Features

- 📚 Academic information and curriculum details
- 📋 Admissions application form
- 👨‍🏫 Staff directory
- 📸 Photo gallery with lightbox
- 📰 News and announcements
- 🤖 Interactive chatbot (Ask Mary Ralake)
- 📱 Fully responsive design

## Color Scheme

- **Primary:** Royal Blue (#1A3A8F)
- **Secondary:** Crimson Red (#CC1A2A)
- **Background:** White (#FFFFFF)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 19
- Vite
- Tailwind CSS v4
- React Router v7
- Framer Motion
- Lucide React Icons
